# LcTTSHub 依赖说明

> 多 TTS（文本转语音）引擎聚合项目。根目录提供统一的 FastAPI 聚合服务与 `tools`
> 共享工具层（模型管理、ASR、文本归一化），各 TTS 引擎作为子项目独立维护。

---

## 1. 运行环境

| 项 | 说明 |
| --- | --- |
| Python | 3.12（项目虚拟环境 `py312env/`） |
| 包管理 | pip（各引擎另提供 `pyproject.toml` / `requirements.txt`，可用 `uv`） |
| 硬件 | 推理需 NVIDIA GPU（CUDA 12.x）；部分引擎支持 CPU 但速度极慢 |
| 模型权重 | 不入库，运行时由 `tools/models_manager.py` 按需从 HuggingFace / ModelScope 下载 |

---

## 2. 共享聚合层依赖（根级）

根级 API 服务（`*_api_server.py`）与 `tools/` 共享层运行所需的公共依赖，
见根目录 **`requirements.txt`**。安装：

```bash
pip install -r requirements.txt
```

核心组成：

- **Web 服务**：`fastapi`、`uvicorn[standard]`、`pydantic`(>=2.9,<3)、
  `python-multipart`、`websockets`、`rich`
- **配置 / HTTP**：`PyYAML`、`requests`、`httpx`(>=0.27)
  （`httpx` 为 **TTS API 管家** `tts_hub_server.py` 的必需依赖：用于把请求**流式透传**
  给各引擎并把响应原样回吐，含 wav 二进制与 SSE 进度流。之前它是间接依赖，现显式声明）
- **模型管理**：`huggingface_hub`、`modelscope`
- **文本归一化**（`tools/text_normalize.py`）：`inflect`、`regex`、`wetext`
- **音频 / 数值**：`numpy`、`soundfile`
- **深度学习框架（最低版本）**：`torch`(>=2.5.0)、`torchaudio`(>=2.5.0)、
  `transformers`(>=4.52.1)
- **GPU 注意力加速**：`flash_attn==2.8.3`（cu128 + torch2.8 + cp312 + win_amd64）。
  Windows 上从源码编译极难，须用预编译 wheel；离线包归档于
  `whl/flash_attn-2.8.3+cu128torch2.8-cp312-cp312-win_amd64.whl`（由 Git LFS 管理），安装：
  `python -m pip install --no-deps whl/flash_attn-2.8.3+cu128torch2.8-cp312-cp312-win_amd64.whl`。
  版本须与运行环境 python(3.12)/torch(2.8+cu128)/CUDA(12.8) 严格匹配。

## 4. 关键版本补丁：packages/index25

`py312env` 默认安装 `transformers==5.3.0`。但 **Audio8 / Confucius4-TTS /
IndexTTS-2.5** 的生成代码针对 transformers 4.x 设计，在 5.x 下 `generate`
行为异常（生成极短静音）。

解决方案：这三个引擎启动时会把 `packages/index25` 插入 `sys.path` 最前面，
优先加载其中的补丁版：

- `transformers==4.52.1`
- `tokenizers==0.21.4`
- `huggingface_hub==0.36.2`

`packages/index25` 已纳入 git（见 `.gitignore` 注释），**请勿删除或忽略**。
若全新克隆后该目录缺失，可手动安装上述版本作为兜底。

### 4.1 关键版本隔离：breezeenv（Breeze-TTS-2 专用）

Breeze-TTS-2 的推理代码要求 **`transformers==4.57.3` + `qwen-tts==0.1.1`**，
与共享 `py312env` 默认的 `transformers==5.3.0` **不兼容**（强行安装会把共享环境
的 transformers 降到 4.57.3，可能波及其它引擎）。因此本引擎单独跑在
`breezeenv/` 虚拟环境中，仅在该环境内覆盖所需版本，互不污染。

创建与安装（Windows，假定已存在 `py312env`）：

```bat
:: 用 --system-site-packages 复用 py312env 的 torch / fastapi / soundfile 等，
:: 仅在 breezeenv 内叠加 Breeze-TTS-2 专属依赖（transformers 4.57.3 + qwen-tts）。
py312env\python.exe -m venv --system-site-packages breezeenv
breezeenv\Scripts\python.exe -m pip install qwen-tts==0.1.1
breezeenv\Scripts\python.exe -m pip install pytest   :: 仅测试需要
```

> 验证：`breezeenv\Scripts\python.exe -c "import transformers, qwen_tts;
> print(transformers.__version__)"` 应输出 `4.57.3`，且 `breeze_infer.runtime`
> 能正常导入。`config/tts_hub.yaml` 中 `breeze_tts.runtime.python` 已指向
> `breezeenv/Scripts/python.exe`，管家启动该引擎时会自动使用。
>
> 模型权重采用 **BreezeBlue 研究与非商用许可**，仅可用于研究与非商用场景。

## 5. 安装顺序建议

```bash
# 1) 创建并激活 Python 3.12 虚拟环境
python -m venv py312env
py312env\Scripts\activate        # Windows
# source py312env/bin/activate   # Linux / macOS

# 2) 安装共享聚合层依赖
pip install -r requirements.txt

# 3) 按需安装具体引擎依赖（以 IndexTTS-2.5 为例）
pip install -r index_tts25/pyproject.toml        # 或用 uv sync
# 或：cd index_tts25 && uv sync --extra webui

# 4) 安装 PyTorch（CUDA 12.8，按需）
pip install torch==2.8.* torchaudio==2.8.* --index-url https://download.pytorch.org/whl/cu128
```

> 各引擎的 `pyproject.toml` 已通过 `[tool.uv.sources]` 配置 CUDA 版 PyTorch 源；
> 使用 `uv sync` 时会自动走 `cu128` 索引。

## 6. 模型权重

模型权重**不入库**，首次运行对应 API 时由 `tools/models_manager.py` 自动下载到
`models/`（可经 `config/*.yaml` 配置路径）。各引擎对应的 HuggingFace / ModelScope
仓库见 `tools/models_manager.py` 的 `MODEL_REGISTRY`。详见根目录
`模型按需下载-不要全下-不下的话会自动下载-自动下载有困难的时候再来下相应的模型.txt`。

**附加的加速适配器（2026-10 新增）**：VoxCPM2 除基座权重 `models/VoxCPM2` 外，
会自动拉取 ModelScope 上的少步数 LoRA `voidful/FDSpeech-VoxCPM2`
（69MB，仅 `lora_config.json` + `lora_weights.safetensors`）到
`models/FDSpeech-VoxCPM2`，由 `config/vox_server.yaml` 的 `lora.enabled` 控制，
关闭后服务即回退为纯基座（详见该配置文件内注释）。

| `启动_auk_api.bat` | AuK | 8021 |

| `启动_dots_api.bat` | dots.tts | 8856 |
| `启动_index_api.bat` | IndexTTS-2 | — |
| `启动_index25_api.bat` | IndexTTS-2.5 | — |
| `启动_omnivoice_api.bat` | OmniVoice | 8853 |
| `启动_omnivoice说书api.bat` | OmniVoice 说书 | — |
| `启动_vox_api.bat` | VoxCPM | 8854 |
